# Kendi Docker İmajını Private Docker Hub'dan Çalıştır

1. `docker.io/kullanici/devops-app:1.0` imaj adını açıklayın.
2. Build, login, push ve private pull sırasını gösterin.
3. ConfigMap ile Secret farkını anlatın; Base64 şifreleme değildir.
4. `imagePullSecrets`in kubelet tarafından imaj çekilmeden önce kullanıldığını anlatın.
